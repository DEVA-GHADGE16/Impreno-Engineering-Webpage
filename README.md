# 🚀 Impreno Engineering Website

A modern, responsive corporate website developed for a precision machining company to showcase its products, clients, and services with a clean and professional UI.
---
## ✨ Features

- ⚡ Fast and optimized performance using Next.js  
- 📱 Fully responsive design (mobile, tablet, desktop)  
- 🧩 Modular component-based architecture  
- 🖼️ Product showcase with interactive hover effects  
- 👥 Client section for business credibility  
- 📞 Contact section with email, phone & location  
- 🎨 Clean UI with Tailwind CSS styling  
---
## 🛠️ Tech Stack

- **Frontend:** Next.js, React  
- **Styling:** Tailwind CSS  
- **Deployment:** Vercel  
- **Version Control:** Git & GitHub
